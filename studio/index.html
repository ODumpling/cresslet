    How it works

    From idea to a live URL in three steps

    1. 1

      Pick a template

      A React app with an API and SQLite, or plain HTML and TypeScript. It opens in the studio, ready to run.

    2. 2

      Edit with a live preview

      Code, terminal and preview side by side. npm install and the dev server run right in your tab.

    3. 3

      Deploy

      One click and it's live on my-app.cresslet.dev, with its own database and files.

    Everything included

    A whole platform, not just a preview

    Every app comes with what it needs to be real, and none of it needs wiring up.

    • Runs in your browser

      npm, a dev server and hot reload run in the tab on Cresslet's own runtime. No VM, no install.

    • Live in a second

      Deploys go live on their own subdomain in under a second. Your last 10 stay a rollback away.

    • Database and files built in

      Each app gets a SQLite database, file storage and secrets. No services to set up.

    • Every app in its own sandbox

      Apps run isolated from each other, with memory, request and network limits.

    • Made for agents

      Templates ship AGENTS.md, every CLI command speaks --json, and the server serves /llms.txt.

    • Open source, self-hostable

      MIT licensed. Run the whole platform on your own server with Node or Docker.
